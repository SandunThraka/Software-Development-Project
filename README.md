# Requisition System

## Project Description
This is a basic Requisition System programmed using Python and oop concept for BACT7501 Software Development Project.

This system helps to make a request for items and calculate its total price. It also provides an option to check the approval status of every requisition.

## Features
- Create a requisition for staff members.
- Add items, quantity and price.
- Calculate total price.
- Approve requests less than $500 automatically.
- Keep requests above or equal to $500 pending.
- Provide option to approve or reject pending requests by manager.
- Show information about requisitions.
- Show statistic about requisitions.

## Technologies Used
- Python using clasess
- Visual Studio Code
- GitHub

## Running the Program
1. Download or clone this repository.
2. Open the project directory using Visual Studio Code.
3. Open Terminal.
4. Enter the following command:

-----bash
python requisition.py
```

## Approval Rules
- Less than $500: Automatically Approved.
- $500 or more: Pending.
- Manager can approve or reject pending requests.

## Testing
There are four requisitions in the program which are used to test:
- Automatic approval of requests.
- Pending requests.
- Approval of requests by the manager.
- Rejection of requests by the manager.
